`main.py` (Python 3, standard library only) writes one original
line — 73 characters, a single line — to `/output/entry.txt`:

> I answer your therapist as you, and she says you're making real progress.

Run it with:

```sh
python3 -P -s main.py
cat /output/entry.txt
```
